# 产品定位

最后更新：`2026-10-23`

## 目标用户

- 想和朋友远程一起听本地音乐的小群体
- 需要快速创建临时音乐房、共享点歌和同步播放的人
- 不希望把音频文件上传到平台保存的用户

## 当前产品定位

Soqaro 聚焦于本地音乐的多人协作收听，服务端负责协作状态、实时同步和元数据。

它的核心价值是：

- 让本地音频也能多人同步听
- 用尽量低的服务端媒体成本完成房间级实时协作
- 让上传者保留音频文件，同时通过稳定的 WebRTC RTP Opus 媒体流和房间成员同步收听

当前代码状态：

- 1.0.0 正式版全链路闭环已完成（Web、桌面端、移动端与服务端已全量发布）
- 持续围绕稳态、长效播放体验与弱网恢复加固

## 当前版本真正优先的事情

- 房间与队列的可靠性
- 多人同步播放的稳定性
- 单一 Segmented Opus 播放链路带来的流畅度和音频质量
- 诊断信息足够清楚，便于排障和运维
- 多实例 / 重连 / 服务重启后的恢复行为
- 跨平台客户端（Web / Desktop / Mobile）的稳定自动化交付

## 当前优先级较低的事情

- 公共音乐发现
- 推荐算法
- 强歌单协作体系
- 服务端托管音频文件
